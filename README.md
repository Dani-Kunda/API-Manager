# API Manager Application

## Overview
This project is a web-based API key management system designed to store and organise API credentials in a structured and accessible format. The application demonstrates structured data handling and secure data organisation concepts.

## Project Objectives
- Create a structured interface for managing API keys
- Store and retrieve API credentials
- Apply basic secure data handling techniques
- Practise web development fundamentals

## Tools & Technologies Used
- HTML
- JSON
- CSS
- Visual Studio Code
- GitHub
- Bolt Platform

## Key Features
- Structured API key storage system
- JSON-based data handling
- Clean and organised user interface
- Simple and accessible layout
- Version-controlled development using GitHub

## Skills Demonstrated
- Web Development
- Data Structuring
- JSON Handling
- UI Design
- Version Control (GitHub)
